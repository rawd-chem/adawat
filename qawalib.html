الخطوة ٣ من ٦

تظهر لكِ صفحة API Keys. إذا وجدتِ مفتاحًا في القائمة، فاضغطي أيقونة النسخ ⧉ في مربعه، وانتقلي إلى الخطوة ٦. وإن لم يوجد مفتاح، فاضغطي «Create API key» في أعلى الصفحة.

الخطوة ٤ من ٦

تظهر نافذة «Create a new key». لا تغيّري شيئًا فيها، واضغطي «Create key»، ثم انتظري ثوانيَ حتى يجهز المفتاح.

الخطوة ٥ من ٦

تظهر لكِ نافذة «API key details». اضغطي أيقونة النسخ ⧉ بجانب API Key. لا تنسخيه يدويًا، فالمفتاح المكتوب غير كامل.

الخطوة ٦ من ٦

عودي إلى المساعد، واضغطي مطوّلًا داخل المربع، واختاري «لصق»، ثم اضغطي «حفظ». تمّ التفعيل 🎉

اختياري — حوّلي اختبارًا جاهزًا من صور أو PDF

صوّري صفحات الاختبار أو ارفعي ملف PDF، فتقرأها الأداة وتكتبها أسئلةً قابلة للتعديل تحت ترويستك.

⚠ مراجعة واجبة: القراءة آلية وقد تخطئ. راجعي كل كلمة ورقم قبل الطباعة، فالرموز والصيغ الكيميائية والمعادلات والجداول والأشكال هي الأكثر عرضة للخطأ.
🔑 تفعيل قراءة الصور (مرة وحدة)
